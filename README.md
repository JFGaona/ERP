Sistema de Gestión para Óptica
Este proyecto es una aplicación web desarrollada con Spring Boot (backend) y React (frontend), diseñada para gestionar de manera integral los procesos de una óptica. Incluye administración de clientes (pacientes), inventario de monturas, historia clínica, roles de usuario, autenticación, y mucho más.

🛠️ Tecnologías utilizadas
Backend: Spring Boot (Java)

Frontend: React

Base de Datos: MySQL (implementada en Azure DevOps)

Arquitectura: Hexagonal (Ports & Adapters)

Control de versiones: Git

Gestión del proyecto: JIRA

 Funcionalidades principales
Gestión de clientes/pacientes con historia clínica.

Registro y control de inventario de marcos de lentes (modelo y cantidad).

Sistema de autenticación con login.

Gestión de roles y permisos.

Visualización y edición de historia clínica por optómetras.

Panel de administración para control general del sistema.
